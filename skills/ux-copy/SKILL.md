# UX copy

- Buttons say what happens: "Create room", not "Submit". Use verbs.
- Errors: say what happened, why (if useful), and how to fix — without blame. "That code doesn't match a room. Check the letters and try again."
- Empty states: explain what goes here and give the first action.
- Be brief, use sentence case, avoid jargon, keep consistent terms for the same thing.
- Offer 2–3 options with different tones when asked for copy.
