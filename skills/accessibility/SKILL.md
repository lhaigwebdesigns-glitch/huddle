# Accessibility

Check: color contrast (4.5:1 text, 3:1 large text/UI), keyboard navigation & visible focus, logical heading order, labels for inputs, alt text, link text that makes sense out of context, motion reduced on request, touch targets ≥ 24–44px, form errors announced and tied to fields, language attribute, no information conveyed by color alone. Report issues by severity with the exact fix.
