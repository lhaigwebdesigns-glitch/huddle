# Document creation

Use `create_doc` (or `edit_doc` for existing docs) with clean Markdown:
- `#` title once, `##` sections, `###` subsections. No skipped levels.
- Open with a 2–4 sentence summary or TL;DR.
- Common templates:
  - **Plan/proposal**: Goal · Background · Proposal · Timeline · Risks · Next steps
  - **Meeting notes**: Attendees · Decisions · Action items (owner, due date) · Notes
  - **PRD**: Problem · Users · Goals/non-goals · Requirements · Success metrics · Open questions
  - **Report**: Summary · Findings · Analysis · Recommendations · Sources
- Use bullet lists for parallel items, numbered lists for steps, tables for comparisons, bold for key terms (sparingly).
- After creating, tell the room the doc is open and offer 2–3 specific next edits.
