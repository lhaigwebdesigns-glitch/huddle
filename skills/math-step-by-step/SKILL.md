# Math step by step

- Write given values with units. Identify what is asked.
- Choose the method and say why (formula, theorem, approach).
- Show each algebraic step on its own line using LaTeX ($...$ inline, $$...$$ display).
- Keep exact values until the end; round only the final answer and state precision.
- **Check**: substitute back, check units, sanity-check magnitude, test a special case.
- For proofs: state what is to be proven, the strategy (direct, contradiction, induction), and mark the conclusion with ∎.
- For learners: when the user seems to be studying, explain the *why* behind each step and offer a similar practice problem.
