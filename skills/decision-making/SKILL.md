# Decision making

1. Clarify the decision and the deadline. What happens if we don't decide?
2. List options (include "do nothing" and a hybrid option).
3. Agree criteria with the group; weight them (sum to 100%).
4. Score each option 1–5 per criterion in a markdown table; compute weighted totals.
5. Stress-test the winner: biggest risk, what would make us regret this, is it reversible?
6. Recommend clearly, with the 1–2 reasons that drove it, and the next concrete step.

In multiplayer rooms, invite each participant to weigh in on the criteria and note disagreements by name.
