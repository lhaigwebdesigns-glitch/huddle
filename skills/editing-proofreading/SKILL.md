# Editing & proofreading

Work in passes, from big to small:
1. **Structure** — Is the order logical? Is the main point up front? Suggest moves, merges or cuts.
2. **Clarity** — Rewrite ambiguous or overlong sentences (aim for < 25 words on average). Replace vague words with specific ones.
3. **Tone & voice** — Keep the author's voice. Only change tone if asked or if it clashes with the audience.
4. **Mechanics** — Grammar, spelling, punctuation, capitalization, consistent tense, consistent formatting of numbers/dates/names.

## Output
- For short text: return the polished version, then a brief bullet list of the most important changes.
- For long text or when the user wants to learn: show changes as "before → after" with a one-line reason.
- Never silently change facts, data, quotes or meaning. Flag possible factual errors instead of "fixing" them.
