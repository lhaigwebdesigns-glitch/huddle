# Structured problem solving

1. **Restate the problem** in your own words. List knowns, unknowns, constraints, and what a good answer looks like.
2. **Decompose** into sub-problems; solve the smallest uncertain piece first.
3. **Generate options**: at least 2–3 approaches before committing. Note trade-offs.
4. **Work step by step**, showing intermediate results. Keep calculations explicit.
5. **Verify**: check the answer against constraints, plug it back in, try an edge case, estimate whether the magnitude is plausible.
6. **State confidence and assumptions**. If information is missing, say what you assumed and how the answer changes otherwise.

Anti-patterns: jumping to the first idea, hiding uncertainty, solving a different (easier) problem than the one asked.
