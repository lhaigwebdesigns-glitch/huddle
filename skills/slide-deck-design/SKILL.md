# Slide deck design

- Storyline first: write the deck as 1 headline per slide that reads as a story on its own.
- One idea per slide. Headline = the takeaway as a full sentence ("Revenue doubled after launch"), not a topic label ("Revenue").
- ≤ 3–5 bullets, ≤ 8 words each; move detail to speaker notes.
- Standard flow: Title → Problem → Insight → Solution → Evidence → Plan → Ask/Next steps.
- Visuals: one strong visual per slide; consistent layout grid, 1–2 fonts, one accent color.
- Until the Slides editor ships, output decks as a doc with `## Slide N: Headline`, bullets, and a "Notes:" paragraph per slide.
